# leetcoin

가상의 부정행위냥이(A)와 천재냥이(B) 이미지 카드를 선택하는 한국어 예측 사이트. BTC/satoshi 입력, 5초 간격 참여 통계, 원금 포함 예상 배당, 2026-11-19 12:00 KST 카운트다운을 제공합니다.

## 현재 운영 상태

배포 기본값은 **모의 거래**입니다. 실제 BTC를 받거나 자동 송금하지 않습니다. 사용자 지정 메인넷 주소는 참고 정보로만 표시합니다. BTCPay 연결은 테스트넷만 허용하며, 서버 연결 정보가 없으면 결제 기능은 닫힙니다. 메인넷 운영, 자동 서명·송금, 실제 서비스 허가 확보는 완료되지 않았습니다.

## 실행 및 검증

Node.js 24 이상. 외부 npm 의존성 없이 실행합니다.

```sh
npm test
npm run build
npm run dev
```

로컬 주소: http://127.0.0.1:4173. 로컬 서버는 127.0.0.1에만 바인딩하고, 항상 모의 운영자 계정으로 실행합니다. 로컬 SQLite는 `.data/`에 저장하며 Git에서 제외합니다. 이 개발 서버를 인터넷에 공개하지 마세요.

## 구현 기능

- 사진 형태로 생성한 두 가상 캐릭터 선택, BTC/satoshi 단위 전환과 즉시 환산
- 확정 참여자의 선택별 고유 인원, 총금액, 비중, 예상 배당을 5초마다 갱신
- 베팅별 입금 요청·계정 매핑, 거래 ID/출력 번호별 중복 방지
- SQLite/D1 영속 원장, 권한 확인, 같은 출처 요청 확인, 정수 satoshi 계산
- BTCPay Greenfield 입금 요청 생성, 서명 검증 웹훅 및 수동 재조회, 불확실한 생성 복구
- 테스트넷 블록체인 주소·금액·확인 수 검증. 기본 3회 확인
- 부분 입금 합산, 초과 입금 환불, 기한 후 입금 환불, 정산 후 추가 입금 환불
- 마감·판정 근거·결과 확정, 중복 정산 방지, 동일 라운드 동시 쓰기 충돌 감지
- 지급 목록 최대 40건씩 예약/CSV 출력, 지갑에서 지급한 거래의 출력과 전송비 검증, 중복 지급 기록 방지
- 실제 전송비 차감 수익, 원장 CSV, 감사 기록
- 실제 통계에 포함되지 않는 별도 99:1 샘플 미리보기

## 돈의 흐름

전체 **유효 베팅액**의 5%를 운영 수수료로 분리합니다. 나머지 95%를 승리한 쪽의 베팅액 비율대로 배분합니다. 1 satoshi 미만 수수료는 내림하고 배당 나머지는 베팅 ID 순으로 배분합니다. 따라서 아주 작은 풀의 실효 수수료는 5%보다 낮을 수 있습니다.

`운영 수수료 수익 = 확정 운영 수수료 − 확인된 지급 거래 전송비`

전송비를 승자의 배당에서 다시 떼지 않습니다. 취소 또는 승리한 쪽의 유효 베팅이 없으면 원금 전액을 환불하고 운영 수수료는 0입니다. 이 경우 운영자가 전송비를 부담하므로 손실이 발생할 수 있습니다. 서버비·세금은 별도입니다.

최소 요청액 0.0001 BTC, 최대 1 BTC. 라운드당 최대 150개 요청, 미완료 요청은 계정당 최대 5개입니다. 종료 1분 전에는 새 요청을 받지 않습니다. 참여 인원은 선택별 고유 계정 수이며 양쪽 참여자는 각각 집계합니다. 가짜 데이터는 여기에 포함되지 않습니다.

## 배포

Sites Worker ES module + D1. `.openai/hosting.json`의 기존 project_id를 유지합니다. `drizzle/0000_ledger.sql`과 journal을 배포 패키지에 포함합니다. 기존의 브라우저 localStorage 모의 내역은 금융 원장으로 가져오지 않습니다.

`src/`는 서버, `public/`은 화면과 이미지, `scripts/build.mjs`는 정적 자산을 Worker에 포함하는 빌드입니다. `dist/`는 생성물이며 커밋 대상이 아닙니다.

자세한 외부 연결과 남은 운영 요건은 [운영 안내](docs/OPERATIONS.md), 이미지 프롬프트는 [이미지 출처](docs/IMAGES.md)를 참조하세요.
