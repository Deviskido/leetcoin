# leetcoin

A/B 선택과 금액 비례 배당을 체험하는 한국어 모의 베팅 사이트.

## 기능

- A/B 선택, 모의 BTC 참여, 잔액 검증
- 참여 현황과 예상 수령액
- 결과 확정, 비례 정산, 취소 환불
- 브라우저 localStorage 저장

실제 BTC 입출금, 지갑 연결, 사용자 인증, 서버 공용 데이터는 구현되어 있지 않습니다. 운영자 버튼 역시 데모용입니다.

## 실행

`dist/index.html`을 브라우저에서 열거나 `dist` 디렉터리를 정적 웹 서버로 제공하세요. 빌드나 의존성 설치가 필요하지 않습니다.

## 정산

전체 풀 × 개인 참여 금액 ÷ 승리한 쪽 총 참여 금액. 정산은 정수 satoshi로 처리하며 나머지는 참여 순서대로 배분합니다. 승리한 쪽에 참여자가 없으면 전액 환불합니다.
